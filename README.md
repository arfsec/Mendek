# Mendek Arena Masteran Burung (Android Flutter)

Aplikasi Android khusus pemasteran burung kicau otomatis dari YouTube dan TikTok.

## Cara Build Jadi APK Release via GitHub Actions:
1. Buat repository baru di GitHub.
2. Upload semua file dalam project ini.
3. Buka tab Actions -> jalankan "Build Android APK Release".
4. Tunggu 3-4 menit, download file APK dari bagian Artifacts.
5. Install di HP Android Anda.
